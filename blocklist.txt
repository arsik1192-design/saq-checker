# =============================================================================
#  CS2Check - список запрещённого ПО
#  Файл читается при каждом запуске. Код править не надо, только этот список.
#  Строки с # - комментарии. Регистр не важен.
# =============================================================================
#
#  [allow]  - свой софт, который не надо флагать. Гасит общие шаблоны
#             вроде "cheat" и "hack", но НЕ гасит точные имена из [strict]:
#             так белый список нельзя использовать, чтобы спрятать чит.
#             Пишите как можно конкретнее, не одно слово.
#
#  [strict] - редкие и характерные имена. Совпадение = флаг ВЫСОКОГО уровня.
#             Ищется как подстрока в любом месте имени файла или пути.
#
#  [loose]  - короткие или пересекающиеся с настоящим софтом имена.
#             Совпадение = флаг СРЕДНЕГО уровня, ищется только как
#             отдельное слово. Эти всегда проверяйте глазами.
#
#  [ext]    - расширения файлов, которые стоит заметить в Загрузках и Temp.
#
#  [size]   - размер файла в килобайтах. Полезно, когда чит переименовывают,
#             но пересобирают редко и размер остаётся прежним.
#
#  Переносить строки между [strict] и [loose] можно свободно: если какое-то
#  имя завалило вас ложными срабатываниями - опустите его в [loose].
# =============================================================================

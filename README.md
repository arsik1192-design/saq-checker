# SAQ Checker

Программа проверки компьютера на следы читов для серверов **SAQ.CS.KZ**.

Игрок запускает её сам, по просьбе администратора. Программа собирает следы,
которые Windows оставляет после запуска программ, и показывает отчёт — сначала
игроку, потом администратору.

**[Скачать последнюю версию](../../raw/main/SAQ-Checker.zip)**

---

## Как пройти проверку

Перед запуском:

- не перезагружайте компьютер,
- не закрывайте CS2 — игра должна быть запущена,
- включите демонстрацию экрана в Discord.

Дальше:

1. Скачайте архив и распакуйте целиком в любую папку.
2. Запустите `START.bat`. Windows спросит права администратора — нажмите «Да».
3. Введите код, который дал администратор.
4. Поставьте галочку согласия и нажмите «Начать проверку».
5. Через 1–3 минуты появится результат. Прочитайте его и отправьте администратору.

Перезагрузка или закрытая игра делают проверку неполной — придётся проходить
заново.

## Почему нужны права администратора

Без них недоступна большая часть того, что проверяется: журналы запуска
программ, список драйверов, журнал файловой системы и список библиотек внутри
процесса игры. Программа, запущенная без прав администратора, соберёт процентов
двадцать данных и честно напишет об этом в отчёте.

## Что собирается

- список запущенных программ, их пути и цифровые подписи
- библиотеки, загруженные в процесс игры `cs2.exe`
- история запуска программ из журналов Windows (Prefetch, BAM, UserAssist)
- список драйверов и настройки проверки подписи драйверов
- записи об удалённых `.exe`, `.dll` и `.sys` из журнала файловой системы
- имена файлов в папках «Загрузки», Temp и «Недавние»
- параметры запуска Steam и целостность файлов игры
- модель компьютера, время работы системы, список устройств

## Что не собирается

- содержимое ваших файлов, документов и переписок
- пароли, куки, история браузера
- снимки экрана
- ничего не отправляется, пока вы сами не нажмёте кнопку

Программа не меняет настройки, не ставит драйверы и не прописывается в
автозагрузку. Отработала, записала отчёт на Рабочий стол, закрылась.

## Антивирус ругается — это нормально

Антивирус смотрит на поведение, а не на смысл. Поведение здесь такое же, как у
вредоносной программы: повышение прав, чтение реестра, перебор процессов, сбор
данных в один файл. Отличить «собирает улики для админа» от «крадёт данные»
автоматика не умеет.

Если Windows покажет синее окно «Windows защитила ваш компьютер» — нажмите
«Подробнее», затем «Выполнить в любом случае».

Мы **не просим** отключать антивирус. Вместо этого: весь код лежит в этом
репозитории открыто. Откройте `CS2Check.ps1` прямо здесь, в браузере, и
прочитайте — там обычный текст, никаких скрытых бинарников.

## Файлы

| Файл | Что это |
|------|---------|
| `START.bat` | запускает программу и запрашивает права администратора |
| `CS2Check.App.ps1` | окно программы |
| `CS2Check.ps1` | сама проверка, вся логика здесь |
| `blocklist.txt` | список запрещённого ПО, обновляется администрацией |

## Что проверка не определяет

Честно, чтобы не было завышенных ожиданий: DMA-читы на отдельной плате, читы на
втором компьютере с картой захвата, аппаратные спуферы мыши и аккуратно
вычищенные следы такой проверкой не ловятся.

Чистый отчёт означает «известных следов не найдено», а не «игрок точно играет
честно». Решение администрация принимает по совокупности: отчёт, демка,
статистика.
